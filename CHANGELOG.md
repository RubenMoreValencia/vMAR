## 0.1.16-alpha — consolidated research baseline

- M0/M1 baseline and experimental M2/M3 multilayer mechanisms.
- Euler/RK4 differential integration, explicit learning memory and control.
- R–C23 contract, trace and numerical parity infrastructure.
- C01 curvature observer remains separately built and non-installed.

The numeric project version is `0.1.16`; `alpha` is the documented
prerelease classification. No stable ABI or 1.0.0 release has been declared.
