# G0.5-E.4.2 — robustness audit under demanding regimes

## Research objective and testable boundary

This study challenges the G0.5-E.4 feedback controller with large proposals,
memory perturbation, variable memory relaxation time, and nonzero memory
coupling. It is a **finite numerical stress test**, not a proof of Lyapunov
stability or optimality.

The original neural field, memory differential equation, explicit Euler and
RK4 integrators, and transaction/rollback contracts are unchanged.

## Experimental matrix — 648 deterministic cases

| Factor | Values |
|---|---|
| Activation | `tanh`, `sigmoid` |
| Integrator | Euler, classical RK4 |
| Initial perturbation | `-0.5, 0, +0.5` applied to first theta and memory components |
| Memory time constant tau | `0.1, 0.6, 2` |
| Memory coupling gamma | `0, 0.2, 0.8` |
| Requested step | `0.1, 1, 10` |
| Maximum attempts | `1, 6` |

Total: `2*2*3*3*3*3*2=648`. Every test starts at time zero from
`theta=[0.2+perturb,-0.4,0.15]` and `m=[0.8+perturb,0,0]`, with
`eta=0.3`, confirmed-memory threshold 0.5, reduction 0.5, acceptance
criterion `L(candidate)<=L(confirmed)`, and tolerance zero.

## Indicators and strict interpretation

Each case records the confirmed final six-dimensional state, actual final
time, loss before/after acceptance (or after rejection rollback), candidate
loss on the last attempt, accepted/rejected attempt counts, field evaluation
count, and effective attempted step. The parity comparison includes **all
numerical columns** and exact integer decision counters.

Outcomes:

- **Immediate acceptance:** candidate accepted without rejection.
- **Recovered acceptance:** one or more proposals rejected, a smaller step
  accepted from the unchanged confirmed state.
- **Exhausted:** no candidate accepted within the configured attempt limit;
  confirmed theta, memory, time and step identifier remain unchanged.
- **Numerical error:** a separate status; it must not be mislabeled as
  rejection. Current C control policy returns such an error instead of
  retrying it automatically.

The controller's success criterion tests *loss monotonicity*, which is
strictly weaker than stability of the full augmented dynamical system.
Comparing final losses across scenarios with different accepted steps/times
is not a controlled accuracy comparison. This protocol diagnoses response,
acceptance behavior and computational expense, not prediction accuracy on
new observations or a generalized theory of learning stability.

## Further scientific work

Examine controlled and uncontrolled fields at matched final time and
evaluation budget, with repeated seeds, independent datasets, and richer
neural architectures. Test boundedness of memory, parameter drift,
Jacobian/eigenvalue regimes, stiff memory relaxation and explicit failure
recovery policy. Extension of activation functions remains a separate
model-contract gate after core control semantics are stable.
