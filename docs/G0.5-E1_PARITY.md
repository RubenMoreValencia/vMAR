# G0.5-E.1 — R–C23 numerical-equivalence audit

## Objective

Verify that independent R and C implementations of the **same differential
field and integrator** produce numerically equivalent states for identical
inputs, time grids and evaluation budgets. Agreement within tolerance is not
bitwise equality and does not imply equivalence of the full neural ecosystem.

## Fixture contract

CSV columns:

`id,integrator,field,dimension,time,step,n_steps,lambda,equilibrium,forcing,state1,state2,expected1,expected2`

For a vector state `y` of dimension one or two, the fixture uses the field:

`F(t,y) = -lambda * (y - equilibrium) + forcing * t`.

The same scalar equilibrium/forcing apply coordinatewise. Euler and RK4
integrate from the same initial state at `time`, using `n_steps` increments
of exactly `step`. The C checker evaluates absolute-plus-relative tolerance:

`abs(C - R) <= 5e-11 + 5e-11 * abs(R)`.

The parser rejects malformed records or unsupported integrators and verifies
field-call counts (`n_steps` Euler; `4*n_steps` RK4).

## Baseline evidence

Eight checked-in decay fixtures derive from the user's executed vMAR.Core
G0.5-D.1 outputs for `h={0.2, 0.1, 0.05, 0.025}` and `T=1`.
The C parity executable passed these eight cases using GCC 14 in the
preparation environment. This is not yet the final macOS/Apple Clang gate.

## Expanded experiment

The R generator `reference/generate_R_fixtures.R` reproduces the baseline
and adds six fixtures:

- Shifted equilibrium (Euler/RK4).
- Non-autonomous forcing proportional to time (Euler/RK4).
- Two-dimensional vector field (Euler/RK4).

The generator must be executed in R before the 14-case claim is valid.
The original 8-case CSV is a baseline fallback and must not be represented
as the expanded 14-case validation.

## Acceptance gate

1. Execute generator from installed/loaded R vMAR.Core.
2. Confirm it reports 14 cases and records R provenance metadata.
3. Build vMAR C with Apple Clang 17 and C23 mode.
4. Run `ctest --test-dir cmake-build-debug --output-on-failure`.
5. Run `./cmake-build-debug/vmar_test_parity reference/vmar_parity.csv`
   to observe each of the 14 case-level comparisons.
6. Record compiler, R version, vMAR.Core version, fixture date and results.

Future extensions: time-dependent eta in the neuronal field, stateful memory,
multi-step learning traces and additional numerical tolerances.
