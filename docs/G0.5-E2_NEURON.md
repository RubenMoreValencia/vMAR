# G0.5-E.2 — first natural-learning neuron in C23

## Mathematical contract (provisional neural promotion)

For observations in rows, `X` with `n` observations and `p` features,
`theta = [w_1,...,w_p,b]`:

```
z_i = sum_j X_ij * w_j + b
yhat_i = phi(z_i)
L(theta) = (1/n) * sum_i (yhat_i - target_i)^2
dL/dw_j = (2/n) * sum_i X_ij * (yhat_i-target_i) * phi'(z_i)
dL/db = (2/n) * sum_i (yhat_i-target_i) * phi'(z_i)
F(t,theta) = -eta * gradient(L(theta))
```

For `tanh`, `phi'(z)=1-tanh(z)^2`; for sigmoid,
`phi'(z)=sigmoid(z)*(1-sigmoid(z))`. The sigmoid implementation is
algebraically stable for positive and negative `z`.

**Original-equivalence gate:** `Euler(F,h)` yields
`theta_next = theta - h*eta*gradient(L(theta))`, matching the original
DSNeuralRNAS neuron parameter update for fixed positive `eta` **when the
data, activation and state agree**, excluding its original stopping logic.
This is an algebraic contract, not yet a blanket behavioral equivalence.

**Alternative integration gate:** classical `RK4(F,h)` evaluates exactly
the same learning field at four intermediate states. RK4 is an alternative
numerical evolution, **not** an optimizer that replaces the philosophy of
natural learning, and it is not expected to produce the same trajectory as
Euler at finite steps.

## API boundaries

`include/vmar/neuron.h` defines `vmar_neuron_problem`,
`vmar_neuron_loss_gradient()`, and `vmar_neuron_field()`.

- Model input `x` uses contiguous row-major doubles (`x[i*p+j]`), unlike
  R's default column-major matrix storage. The R parity generator explicitly
  creates a `byrow=TRUE` matrix of the same mathematical values.
- The input `theta` is contiguous weights then bias; its dimension is `p+1`.
- Prediction output is optional; the gradient has `p+1` elements.
- The field consumes an immutable dataset and a **constant eta**. Dynamic
  learning-rate callbacks, memory state, feedback control, stopping criteria,
  and arbitrary MLP topologies belong to later versioned contracts.
- All data and parameters are checked for finite values and shape/size
  overflow. Caller manages memory; no internal heap allocations.
- The neural gradient and prediction outputs are unspecified on an error.
  Integration output retains `vmar_step()`'s rollback contract.
- Caller must supply nonoverlapping buffers and preserve dataset lifetime.

## Evidence and acceptance

Local GCC draft-C23 compile with strict warnings passed 58 neural assertions
covering both activation functions, finite-difference gradient checks,
field identity, Euler equivalence, RK4 finite outputs, and invalid inputs.
The existing differential library passed 47 earlier assertions.

The R-C23 **neural parity gate is pending** until the original R vMAR.Core
reference runs on macOS. The new R fixture generator creates **16 cases**:
2 activations x 2 integrators x 2 step sizes x 2 trajectory lengths.
Each records initial loss, three gradients, three predictions, three final
parameters, and final loss. Tolerance: absolute + relative `5e-11` each.

## Research limits

Passing these fixtures establishes numerical parity **for these reference
cases only**. It does not establish improved convergence, generalization,
adaptive stability, formal XAI, MLP equivalence or the complete philosophy
of DSNeuralRNAS. Those claims require separate experimental gates.
