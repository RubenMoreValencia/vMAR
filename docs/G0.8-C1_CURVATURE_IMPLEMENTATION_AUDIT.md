## Files and architecture

- `include/vmar/curvature.h`: explicit opt-in callback, dimension, step,
  loss budget, caller-owned workspace, transactional report API.
- `src/vmar_curvature.c`: symmetric finite-difference Hessian; mirrored
  off-diagonal calculations; no eigenvalue solver or intervention policy.
- `tests/test_curvature.c`: quadratic mathematical contracts, numerical
  and negative-domain tests, transactional state and budget invariants.
- `tests/test_curvature_parity.c`: conditional CTest oracle against a
  genuine R-generated 972-coordinate, 12-case neural Hessian fixture.
- `reference/generate_R_curvature_parity.R`: independent R fixture
  generator using the fixed G0.8-B.1 network and trajectories.

The CMake option `VMAR_BUILD_EXPERIMENTAL_CURVATURE` enables the research
library and tests. Disabling it retains the original stable build.

## Numerically defined contract

For `p` parameters and finite `h > 0`, the code computes:

\[
H_{ij} = \frac{L(\theta+h e_i+h e_j)-L(\theta+h e_i-h e_j)
-L(\theta-h e_i+h e_j)+L(\theta-h e_i-h e_j)}{4 h^2}.
\]

Only upper-triangular pairs are evaluated; symmetric coefficients are
mirrored into a separate temporary matrix. The code commits the complete
output *only on success*. Thus it performs exactly `2p(p+1)` callback
evaluations and uses `p²+p` caller-owned doubles of workspace.

Default resource boundary: `p <= 16`; the caller can choose a stricter
limit and must supply `max_loss_calls >= 2p(p+1)`. There are no hidden
allocations. Invalid or indistinguishable perturbations, non-finite
losses, callback failure, invalid buffer aliasing and insufficient
workspace return errors without changing the output or report.

**Limits:** the returned `symmetry_error=0` follows by construction; it
does not certify numerical accuracy. The initial experimental module
does not classify eigenvalues or infer a stationary saddle point. The
caller is responsible for a smooth objective and for comparing steps
to assess cancellation. The cost of a full dense Hessian still scales
quadratically with `p`.

## Promotion stop conditions

- The C Hessian differs from R beyond predeclared per-coordinate
  tolerance `1e-5` for the fixed neural reference scenarios.
- New code breaks any existing vMAR-C23 contract or modifies M0/M1/M2/M3.
- A callback failure leaves a success-looking Hessian or report.
- Any selected dimension is evaluated without a declared budget.
- Eigenvalue/curvature classifications are added without independent
  numerical tests and explicit uncertainty handling.
