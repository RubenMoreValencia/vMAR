# G0.5-E.5.2 — Adaptive activation, memory and feedback control

## Contract and research status

This milestone extends G0.5-E.5.1 without modifying the validated built-in
neuron, fixed activation, or integrator APIs. The state is the concatenation
`S=[theta(d),m(d)]`, where `theta=[w,b,alpha]` for trainable activation
parameters; fixed activation parameters are not part of theta.

Given custom activation neuron loss `L(theta)` and gradient `g(theta)`, define:

```
theta' = -eta * (g(theta) + coupling * m)
m'     = (g(theta) - m) / tau
```

`tau>0`, `eta>0`, `coupling>=0`. With `coupling=0`, memory **observes** gradient
history and does not change the parameter trajectory. Coupling is an explicit
research intervention, not a proven optimizer. Activation parameters evolve
under the same mathematical rule as weights and bias.

## Transaction and memory gate

The controller takes a confirmed state, initial step, backtracking fraction,
maximum attempts, loss tolerance and optional memory threshold. It tests
candidate trajectories produced by Euler or RK4, starting every attempt at
the original confirmed state and time. When the infinity norm of the
**confirmed** pre-step memory exceeds the positive threshold, the first
proposed step is reduced once. A proposal is accepted iff:

```
candidate_loss <= confirmed_loss + loss_tolerance
```

Acceptance commits **all** theta/memory coordinates, time and step ID.
Exhaustion rejects the transaction, preserving the original state and
metadata. Returned diagnostics distinguish attempts, rejected attempts,
field evaluations, initial loss, last candidate loss and actual step.

This policy supervises loss, not Lyapunov stability or generalization; its
monotonic criterion should not be mistaken for a universal guarantee.

## Scientific next gate

Require comparisons with observational memory (`coupling=0`) at matched final
time and field-evaluation budget; include perturbations, different initial
activation parameters, rejection/exhaustion, singular or nonsmooth regions,
and reproducible numerical traces. Test whether feedback adds explanatory
value beyond standard gradient flow and whether it decreases robustness.
