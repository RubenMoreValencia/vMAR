# G0.7-B — Extensible multilayer network, first C23 implementation

**Status:** independently compiled C23 implementation; R–C23 numerical
parity is a separate gate that must be executed against R-generated fixtures.
R reference: `vMAR.Core` 0.0.13 (413 R checks reported passing).
C library/API version: 0.1.13-alpha.

## Mathematical scope

For each affine layer `l`, with widths `n[l]` and `n[l+1]`:

`z[l] = W[l] a[l-1] + b[l]`, `a[l] = phi[l](z[l])`.

The initial regression contract has **one scalar output** and
`L(theta) = sum_i (prediction_i - target_i)^2 / N`.
The C23 implementation evaluates analytic gradients by backpropagation and
exposes `dtheta/dt = -eta * gradient(L(theta))` as a callback. Euler and RK4
integrate the **identical** mathematical field; they are integration choices,
not two kinds of learning. RK4 is not treated as an optimizer.

## Canonical representation and resource contracts

- Public API: `include/vmar/network.h`, implementation `src/vmar_network.c`.
- Descriptor: positive widths, at least one affine layer, final width one;
  exactly one supported built-in activation per layer.
- Packed `theta`: each layer contributes weights in **row-major order**
  (`W[output,input]`), then the output biases; layers are concatenated.
- Dataset: observations in rows, flattened as `x[i * input_width + j]`.
- Explicit state dimension, layer offsets, total parameter count and
  caller-supplied workspace. The module performs **no allocations**.
- Workspace requirement is returned in numbers of `double`, not bytes.
  The caller must supply disjoint storage as documented in the header.
- Invalid arguments, workspace shortage and non-finite arithmetic yield
  `vmar_status`, not an implicit alternative learning rule.
- Activation convention at ReLU's kink matches the existing C23 neuron
  catalog; no differentiability theorem is asserted at that point.

## Accepted tests and scientific limits

The independent C test `tests/test_network.c` covers:

1. One-hidden-layer historical fixture and its known forward/loss values.
2. Three affine layers (`2 → 3 → 2 → 1`) and row-major packing.
3. Analytic gradient versus independent central finite differences.
4. Gradient-flow callback integrated with Euler and RK4.
5. Descriptor, dimension, numeric and workspace error contracts.

Local Linux GCC `-std=c2x` result: **171 assertions, 0 failures**.
This is not a substitute for Apple Clang/C23/CLion validation.

compares each coordinate and loss within `2e-10 * (1 + abs(reference))`.

## Boundary and next promotion decision

- Included: deterministic scalar-output MLP, layer-specific activations,
  analytic gradients and the differential field.
- Reused but not silently embedded: generic integrators, memory, control,
  diagnostics, FormalSpec trace contracts.
- Not yet promoted: multivariate output/loss, trainable custom activation
  parameters inside arbitrary layers, integrated multilayer-memory-control
  trajectories, optimizer comparison, automatic architecture discovery.

**Proposed next gate G0.7-B.1:** confirm R–C23 parity on Rubén's Mac, run
the full historical strict fixture suite, and only then audit the coupled
multilayer state `(theta, memory, control)` without multiplying redundant
algorithms or tests.
