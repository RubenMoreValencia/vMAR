# G0.7-B.2 — Effective contribution of multilayer memory and control

**Pre-registered decision:** This is the last bounded experiment needed to
decide whether the first-memory coupling should remain a configurable
research feature. It is **not** a search for a universal law from a tiny
benchmark. The equations and code of G0.7-B.1 are unchanged.

## Context already validated on the researcher's Mac

- 14/14 historical R fixtures recovered by original generators.
- The strict C23 configuration with Apple Clang 17 built and **37/37 tests
  passed**, including the historical parity gates.
- The prior vMAR.Core 0.0.14 checked cleanly (428 testthat assertions).
- Coupled multilayer R–C23 parity passed: 320/320 state coordinates.

## Experimental policies

| Policy | Differential state | Coupling | Control |
| --- | --- | --- | --- |
| M0 | theta, observational memory frozen | 0 | none |
| M1 | theta + evolving memory | 0 | none |
| M2 | theta + evolving memory | 0.2 | fixed step |
| M3 | theta + evolving memory | 0.2 | loss-gated backtracking |

M0 is evaluated via the same `vmar_network_field` as G0.7-B. M1 and M2
share `vmar_network_system_field`; M3 uses the same field and
`vmar_network_control_step`. M0's memory is not integrated and must not
be used as an outcome measure. M0 and M1 **must** have equivalent theta and
loss; this is a test of correct separation of observation and influence.

## Predefined design

- Architecture: 2–3–2–1, activations tanh/sigmoid/identity.
- Three fixed input observations, same scalar targets and initial theta.
- Theta perturbations: -0.05, +0.05 per coordinate.
- Initial first memory: +/-0.5 in the first component, others zero.
- Integrators: Euler and classical RK4, same mathematical differential field.
- Four policies × two perturbations × two memory signs × two integrators
  = **32 controlled/fixed trajectories**.
- Target horizon `T=0.5`, proposal `h=0.05`, `eta=0.2`, `tau=0.7`.
- M3: rejection ratio 0.5, at most four proposals per step, memory gate 0.2.
- All tests report whether each trajectory **reached the same horizon**.
- Numerical costs count Euler as one field evaluation and RK4 as four per
  candidate; rejected proposals are included in cost.

## Claim gates and interpretation

1. **Correctness:** M0 and M1 theta/loss trajectories coincide; all values
   finite; C and R agree per scenario.
2. **Paired contribution:** M2 minus M1 and M3 minus M1 for *identical*
   method, theta perturbation and initial memory.
3. **Time equivalence:** do not compare final loss if either policy failed
   to reach `T`.
4. **Computational cost:** report field evaluations and rejected proposals;
   equal final time does not imply equal computational budget.
5. **Promotion:** keep a policy only as an optional, explainable extension
   when it brings reproducible, economically justified benefits within the
   tested regimes. Otherwise retain as observable reference or disable it.

This phase does **not** claim equal-gradient-budget superiority or infer
general stability from the 32 trajectories. A later cross-problem test would
be required for a wider statistical conclusion.

## Reproduction

Run from `vMAR.Core` in R:

```r
source("tools/verify_documentation.R")
devtools::test()
devtools::check()
devtools::load_all()
```

Then switch to `vMAR` root:

```r
source("reference/run_R_multilayer_value_audit.R")
```

This generates two **new**, non-destructive files:

- `reference/vmar_multilayer_value_audit.csv` (32 scenario metrics).
- `reference/vmar_multilayer_value_contrasts.csv` (16 paired contrasts).

In CLion terminal, configure **after** generating the R fixture:

```sh
cmake -S . -B cmake-build-scientific -DCMAKE_BUILD_TYPE=Debug \
  -DVMAR_STRICT_PARITY_FIXTURES=ON
cmake --build cmake-build-scientific
ctest --test-dir cmake-build-scientific --output-on-failure
./cmake-build-scientific/vmar_test_network_value_audit \
  reference/vmar_multilayer_value_audit.csv
```

The C test also supports `--smoke` and is always registered with CTest:
it checks 32 C scenarios and M0/M1 equivalence even before R fixtures exist.
The R–C23 parity CTest is registered only when the new 32-row CSV exists.

## Scope limit

Do not modify Adam or RK4 as part of this milestone. RK4 remains an
integration benchmark; Adam remains an independently audited reference.
Avoid adding more activations or architectures until the experiment shows
where memory and control measurably contribute.
