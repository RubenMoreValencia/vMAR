# G0.5-E.4.1 — experimental stability, memory and feedback audit

## Status and purpose

This is a reproducible **experimental protocol**, not a mathematical
stability theorem. The C23 core API is unchanged. This milestone adds
independent R reference fixtures and a C23 parity test covering the
previously validated neural, memory and controller contracts.

The scientific questions are: (i) does observational memory preserve the
uncoupled neural trajectory; (ii) what changes with memory coupling;
(iii) how much computational work does the controller require;
(iv) how do integrators compare at fixed final time and equal field budget;
(v) how sensitive are outcomes to a declared initial perturbation?

## Fixed protocol and experimental factors

Dataset: same 3x2 row-major mathematical dataset and targets as E.2–E.4.
Initial `theta=[0.2+perturb, -0.4, 0.15]`, where
`perturb in {-0.1, 0, 0.1}`. Memory starts `[0,0,0]` for baseline or
`[0.8,0,0]` otherwise. Constant `eta=0.3`, `tau=0.6`.

Scenarios:

- `baseline`: zero memory, zero coupling.
- `observe`: nonzero initial memory, zero coupling.
- `coupled`: nonzero initial memory, coupling 0.2.
- `control`: same coupled field, plus confirmed-memory threshold 0.5,
  proposed step 0.2, reduction 0.5, at most six attempts per proposal,
  and acceptance iff candidate loss <= confirmed loss.

### Phase I — fixed final time (36 cases)

2 activations x 2 integrators x 3 scenarios x 3 perturbations.
Twenty steps of h=0.05 give T=1 for every case. The error reference is
**numerical**, classical RK4 at h=0.005 with 200 steps for the same field;
it is not an exact analytic solution. Euler uses 20 evaluations, RK4 80.

### Phase II — controlled proposals (12 cases)

2 activations x 2 integrators x 3 perturbations, always the coupled
scenario. Exactly 20 proposals are made, each with up to 6 attempts.
Records include accepted/rejected attempts, field calls and final time.
**Final times may differ; losses from this phase are not compared as if
time were held constant.** A further fixed-time controlled study needs a
time-target controller and appropriate stopping diagnostics.

### Phase III — equal field evaluation budget (36 cases)

2 activations x 3 scenarios x 3 perturbations x 2 integrators.
Both methods reach T=1 at 20 field evaluations: Euler with 20 steps
of h=0.05, RK4 with five steps of h=0.2. This is equal **field evaluation
budget**, not equal CPU time or equal accuracy.

## Recorded observables

Every row records activation, integrator, scenario, perturbation, achieved
time, final loss, largest absolute theta/memory components **observed at
completed steps**, error relative to high-resolution numerical reference
(only fixed-time and equal-budget phases; -1 sentinel otherwise), counts
of accepted/rejected attempts, number of field evaluations, and final
augmented state.

Do not interpret sampled maximum as a continuous-time upper bound; hidden
intermediate extrema may exist. Reproducibility requires fixed compiler and
floating-point settings, documented tolerance and actual R outputs.

## Acceptance gates

1. R script runs to completion and yields 84 records: 36+12+36.
2. Independent C parity test compares **all numerical columns** within
   `5e-10 + 5e-10*abs(R)`, plus exact counters and scenario metadata.
3. Baseline and observational neural states agree with zero coupling.
4. No invalid non-finite values or unexplained rejected/error transitions.
5. The scientific report separates: numerical parity, observational
   trajectory differences, comparative accuracy and performance claims.

No hypothesis of general superiority may be accepted solely from these
three starting points or a three-observation illustrative neural dataset.
Broader datasets, stiffness regimes, input noise, varied timescales,
replicates and independent baselines remain mandatory for generalization.
