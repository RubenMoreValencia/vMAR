# G0.9-A.1 — Public API, installation and versioning audit

**Status:** implementation audit and Linux GCC consumer smoke test passed;
**public release is not yet authorized**. This is an evidence record, not
a declaration of final macOS/Apple Clang or strict R–C23 parity validation.

## 1. Frozen mathematical scope

- `vmar_core` is the supported candidate for public installation.
- Canonical C23 public headers are installed from `include/vmar/`.
- Public numerical core: explicit vector fields and Euler/RK4.
- Neural layer: scalar-output multilayer forward/gradient calculations.
- M0/M1 baseline; M2/M3 explicit opt-in experimental interventions.
- C01 curvature, discrete Adam and other comparison research targets are
  **not** installed as part of `vmar::core`.
- FormalSpec Ψ/Γ/Φ remain normative in the separate R package.

No numerical equation, memory layout, default mechanism or existing
public function signature was changed by G0.9-A.1.

## 3. Version and compatibility contract

`CMakeLists.txt`: `project(vMAR VERSION 0.1.16)`;
`include/vmar/vmar.h`: API version `0.1.16`;
documentation: `0.1.16-alpha` prerelease.

`SameMajorVersion` is a CMake package-selection policy, **not** a claim
of ABI stability. Because the major version is `0`, breaking API changes
remain possible and must be documented in the changelog. Patch/minor
increments must not silently mutate canonical state semantics.

Keep English canonical for source, API and mathematical contract files;
the Spanish README supplies a corresponding scientific and practical
entry point.
