# G0.5-E — C23 differential-core promotion contracts

## Promotion decision

Approved for initial C port: vector state, explicit field callback, one-step
Euler, one-step RK4, numerical validation, explicit workspace, and analytical
reference tests. **Not** yet promoted: R natural-learning neuron, dynamic
eta callbacks, memory-based adaptation, FormalSpec traces, adaptive step
selection, and neural graph APIs. These remain R research work.

## Mathematical equations

The generic field is `dy/dt = F(t,y)`; the field is supplied by the caller.
Euler: `y_next = y + h*F(t,y)`.
RK4: `y_next = y + h*(k1+2*k2+2*k3+k4)/6`, with four distinct stage states.

## Numerical tolerances

For the reference equation `y'=-y`, `y(0)=1`, `T=1` with `h=0.1`:

- Independent analytic oracle: `exp(-1)`.
- Euler R reference: `0.34867844010000`.
- RK4 R reference: `0.36787977441250`.
- Reference differences in C unit tests: absolute <= `5e-13` for RK4
  fixture, <= `1e-13` for Euler fixture, plus independent analytic bounds.

These numerical tolerances are initial fixture-specific contracts, **not**
universal floating-point error guarantees for arbitrary fields.

## Environment evidence gate

1. CLion CMake configure and build must succeed with `C_STANDARD 23`.
2. Apple Clang 17 must report `__STDC_VERSION__ = 202311L`.
3. `vmar_test_core` and `ctest --output-on-failure` must pass.
4. Confirm debug with LLDB and, separately, UBSan/ASan when available.
5. Record compiler/OS/CMake build details and attach test results.

The initial source was compiled and tested with GCC 14 `-std=c23` in the
preparation environment (47 assertions, zero failures; UBSan passed).
GCC advertises draft `202000L` there, so the compiler-conformance gate is
**not** certified until executed on Apple Clang in the user's environment.
