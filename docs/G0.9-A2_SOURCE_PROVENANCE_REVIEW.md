# G0.9-A.2 — Source provenance and conditional MIT adoption

**Decision history:** MIT preparation was initially conditional; on
2026-11-22 the researcher ratified provenance and publication identity.
The root `LICENSE` was subsequently activated as MIT. An official GitHub
release remains unpublished, and independent source-history verification
has not been claimed.

## Checked in the current project snapshot

- The installable C23 core comprises the `src/vmar_*.c` files named in
  the `vmar_core` target of `CMakeLists.txt`, with public interfaces under
  `include/vmar/`.
- A text scan of `src/`, `include/`, and the build definition found no
  explicit copyright, SPDX, vendor-origin, or third-party attribution
  declarations in these source files. **Absence of notices does not
  establish original authorship or the right to relicense.**
- `vMAR.Core` in R separately declares `MIT + file LICENSE` in its
  DESCRIPTION; that declaration does **not** license the C23 project.
- C23 programs use system C headers and standard mathematical functions;
  installed dependencies and toolchain licensing must be reviewed only
  insofar as they impact the distributed deliverables.
- Reference fixture CSVs are generated from R research programs and may
  be distributed with the source archive only after reviewing their data
  provenance and the permissions applicable to any underlying datasets.
- Existing audits document source-equivalent DSNeuralRNAS behaviors and
  mathematical references. Functional equivalence alone does not determine
  source-code provenance.

## Source-by-source provenance checklist

| Category | Initial finding | Required final evidence |
|---|---|---|
| C23 source files (`src/`) | No embedded ownership/license statements located | Author's declaration of ownership and a history of any copied/modified sources |
| Public headers (`include/vmar/`) | No embedded third-party notices located | Same ownership and third-party review |
| C tests and examples (`tests/`, `examples/`) | Research-developed fixtures and tests; ownership not independently verified | Confirmation of authorship and dependencies |
| R-derived references (`reference/`) | R scripts and parity fixtures, some generated | Underlying data provenance, reproduction procedure, and reuse permission |
| Earlier DSNeuralRNAS projects | Referenced as mathematical and semantic antecedents | Confirm original author/contributor rights and whether any code was incorporated verbatim |
| External contributions | Not established from this snapshot | Review commit history and contributor permissions when repository history becomes available |

## Remaining diligence before publishing

1. Preserve the author's ratification as part of the provenance register;
   separately inspect any previously unrecorded contributor or third-party
   ownership claims once full repository history is available.
2. Review all third-party code, generated data, copied formulas in code,
   tests, and external contributions against their original terms.
3. Resolve any incompatible material by obtaining permission, replacing it,
   or excluding it from the MIT distribution.
4. The root MIT `LICENSE` has been activated following author ratification;
   avoid presenting the ratification as independent third-party clearance.
5. Update README and citation documentation; record the exact Git commit,
   source archive, and checksum of the release.

**This static review is not a legal determination of source ownership.**
