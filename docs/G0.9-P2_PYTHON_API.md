# G0.9-P.2 — Direct Python API (`from vmar import Differential`)

**Status:** Experimental, locally validated on Linux with GCC 14 / Python 3.12.
Google Colab, macOS and separate Python versions still require independent runs.
This is a Python package distribution; it has **not** been published to PyPI.

## Installation from source (Linux/Colab; macOS with Xcode CLI)

Requires Python >= 3.9, a C compiler capable of the subset of C23 used by
vMAR (`-std=c2x`), and Python build requirements (`setuptools`, `wheel`).
No NumPy, Matplotlib or CMake is needed by the Python application.

```sh
python -m pip install "git+https://github.com/RubenMoreValencia/vMAR.git"
```

This compiles the C23 source files into the native Python extension during
installation. `vmar._native` is a Python extension exporting the C symbols;
`vmar.differential` calls those symbols with `ctypes`. There is **one** Euler/
RK4 implementation, the original C23 code. The pip distribution name is
`vmar-dynamics`; the import name is `vmar`.

## Minimal example

```python
from vmar import Differential

modelo = Differential(
    field=lambda t, y: (-y[0],),
    initial_state=[1.0],
)
resultado = modelo.integrate(method="rk4", step=0.1, steps=10)
print(resultado.state)  # (0.3678797744124984,) approximately
print(resultado.times)  # 11 time values, including t=0
```

The return value is an immutable `Trajectory` with `times`, `states` and
`state` (last state). The callback receives `time` and an immutable tuple;
it must return a finite vector of equal dimension. Errors are raised as
`ValueError`, `TypeError`, or `VmarError`, not silently ignored.

## Scientific boundaries

- A Python wrapper is **not** a separate integrator or learning algorithm.
- It is synchronous and incurs callback cost for every field evaluation.
- Only Euler and RK4 differential integration are currently exposed.
- Neuronal states, adaptive activation, learning memory, control, FormalSpec
  traces and C01 curvature are **not** represented by this Python API.
- Compiler-level numeric parity is tolerance-based, not bitwise guaranteed.
- The C23 API and pre-1.0 Python API should not yet be interpreted as a
  frozen ABI or production-grade Python package.

## Verified local gate

Built a wheel (`vmar-dynamics==0.1.16a1`) from source using GCC and installed
it into an independent Python target directory. Four tests passed:
one-dimensional R reference at `t=1`, vector dimension + RK4 field call count,
input/callback failures, and zero-step behavior. The core C23 library and
earlier experimental Colab notebook remain available unchanged.
